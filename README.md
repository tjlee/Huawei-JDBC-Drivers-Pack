# Huawei-JDBC-Drivers-Pack

<!-- Plugin description -->
**Huawei-JDBC-Drivers-Pack** bundles JDBC drivers for GaussDB, MySQL, MongoDB, PostgreSQL, ClickHouse, OceanBase, and Redis directly into the plugin — no internet access required during driver setup.

On first use, a license agreement dialog presents all bundled driver licenses for review. After acceptance, the drivers are installed automatically to your IDE configuration directory and immediately usable in Database Tool Window connections.

**Bundled drivers:**
- GaussDB 8.6.1 — with IAM (Access Key) authentication support
- MySQL Connector/J 9.5.0
- MongoDB JDBC Driver 1.21
- PostgreSQL JDBC 42.6.0
- ClickHouse JDBC 0.9.4
- OceanBase Client 2.4.14
- Redis JDBC Driver 1.6
<!-- Plugin description end -->

## Installation

- Using the IDE built-in plugin system:

  <kbd>Settings/Preferences</kbd> > <kbd>Plugins</kbd> > <kbd>Marketplace</kbd> > <kbd>Search for "Huawei-JDBC-Drivers-Pack"</kbd> > <kbd>Install</kbd>

- Manually:

  Download the [latest release](https://github.com/tjlee/Huawei-JDBC-Drivers-Pack/releases/latest) and install it manually using
  <kbd>Settings/Preferences</kbd> > <kbd>Plugins</kbd> > <kbd>⚙️</kbd> > <kbd>Install plugin from disk...</kbd>
